# Granite Resonance — 오디오 반응 피드백/노이즈 인터랙션

## 실행
- **start.command** 더블클릭 → 로컬 서버 + Chrome 창으로 실행 (처음 한 번 카메라 권한 허용)
- **start_kiosk.command** → 전시용 전체화면, 클릭 없이 자동 시작 (종료: Cmd+Q)
- macOS가 막으면: 파일 우클릭 → 열기 / 또는 터미널에서 `chmod +x *.command`

## 폴더 구조 (미디어아트 폴더 기준)
```
미디어아트/
├─ Granite Resonance.wav     ← 이 폴더나 audio/ 에 넣은 음원이 자동으로 목록에 뜸
├─ audio/                    ← 추가 음원 (wav, mp3, m4a, aif, flac…)
├─ video/                    ← 카메라가 없을 때 쓸 대체 영상 (mp4, mov, webm)
│   └─ fallback_demo.mp4     ← 데모용, 실제 영상으로 교체하세요
└─ FeedbackNoise/            ← 작품 (index.html + 실행 스크립트)
```

## 입력 처리
| 모드 | 동작 |
|---|---|
| 자동 | 카메라 사용 → 끊김·검은 화면·멈춤이 3.5초 지속되면 대체 영상으로 크로스페이드, 4초마다 재연결 시도, 돌아오면 다시 카메라로 |
| 카메라만 | 대체 없음 (점검용) |
| 대체 영상만 | video/ 의 영상 또는 직접 연 파일 |
| 생성 패턴만 | 영상 파일 없이 셰이더로 만든 화강암 패턴 |

대체 영상이 없거나 재생 실패하면 생성 패턴으로 자동 전환됩니다.

## 오디오
- 음원 파일(폴더 자동 검색 + 파일 열기) 또는 **실시간 입력**(마이크/오디오 인터페이스 라인 입력) 선택
- 저음 → 줌·왜곡·흩날림 / 중음 → 회전·흐름 / 고음 → 노이즈·떨림 / 킥 → 터짐·되감기
- 밴드별 자동 레벨 조정이 들어 있어 음원 음량이 달라도 반응 폭이 비슷하게 유지됨

## 표현 방식 (M키로 전환)
- **피드백** / **파티클** / **피드백+파티클**
- 파티클 스타일 (5~7키)
  - **5 흩날림**: 밝은 안개 배경 + 어두운 입자로 된 인물. 가장자리·움직이는 부위부터 바람에 흩어짐
  - **6 연기**: 검은 배경 + 미세한 흰 입자가 연기/비단처럼 흐름
  - **7 빛 입자**: 영상 색을 입은 입자 + 피드백
- 형체 감지: **자동**(카메라=배경 차분, 영상=형체 대비) / 배경 차분 / 형체 대비 / 어두운·밝은 형체 / 영상 밝기
- 카메라 사용 시: 전시장에 **사람이 없을 때 B키**로 배경을 학습시키면 관객만 정확히 입자로 바뀜

## 타임워프 (글리치 대체)
최근 장면(기본 4초)을 기억해 과거를 현재 위에 겹침
- **과거 잔상 겹침**: 0.5초 간격의 과거 장면 4장이 따뜻하고 옅게 포개짐
- **시간 왜곡**: 화면 부분마다 조금씩 다른 과거가 흐름
- **킥에 되감기**: 강한 킥에 잠깐 과거로 돌아갔다 현재로 복귀

## 데모 영상
`video/demo_figure.mp4` (움직이는 두 실루엣)로 카메라 없이 파티클 효과를 확인할 수 있음. 실제 영상으로 교체 가능.

## 단축키
H 패널 · F 전체화면 · Space 재생/정지 · N 다음 곡 · C 카메라 재연결 · X 잔상 지우기
M 표현 방식 · 1–4 피드백 프리셋 · 5–7 파티클 스타일 · B 배경 다시 학습 · I 상태 표시
슬라이더 더블클릭 = 기본값. 설정은 브라우저에 자동 저장됨.

# 관객 감지 서버 (SAM 3 / SAM 2)

GoPro 화면에서 사람을 한 명씩 분할·추적해 작품에 **사람 수 · 위치 · 화면 속 키**만 보냅니다. 영상은 저장하지 않습니다.
작품은 사람 한 명마다 새 한 마리를 짝지어, 멀면 높이 맴돌고 다가오면 내려오며, 바로 앞이면 가지에 앉아 빛납니다.

## 처음 한 번
1. `setup_vision.command` 실행 (Python 3.10 이상 필요, 10분 정도)
2. SAM 3를 쓰려면 https://huggingface.co/facebook/sam3 에서 접근 요청 → 승인 후 설치 중 로그인 (`hf auth login`)
   - 승인 전이거나 로그인하지 않으면 자동으로 SAM 2(YOLO 추적 + SAM 2.1 분할)로 동작합니다.

## 실행
- `../start.command`가 감지 서버를 함께 켭니다 (설치돼 있을 때). 로그는 `vision.log`.
- 단독 점검: `./start_vision.command --show` (감지 상자가 그려진 확인 창)
- 카메라 번호: `./start_vision.command --list` → `--camera 1` 처럼 지정
- 방식 지정: `--backend sam3 | sam2 | yolo | mock` (mock = 카메라 없이 가상의 관객)

## 거리 보정
작품 화면의 "카메라 감지" 패널에서 **'멀리' / '바로 앞' 기준(화면 높이 중 사람 키 비율)** 을 현장 거리에 맞춰 조절합니다.

## 참고
- SAM 3는 큰 모델이라 Mac(MPS)에서는 초당 몇 장 수준일 수 있습니다. 새의 반응은 느린 움직임이라 충분하지만, 버벅이면 `--backend sam2`가 가볍습니다.
- 감지 서버가 꺼져 있으면 작품은 브라우저 카메라의 움직임 덩어리로 사람 수를 대략 나눠서 동작합니다.

|---|---|---|---|
| **말을 걸어 두는 나무** · Words Left on a Tree | 2026 | [`가시나무에_매달린_말들/`](가시나무에_매달린_말들/) | `start.command` (전시용 `start_kiosk.command`) |

## 작품 랜딩페이지 (`landing/`)

작품 제어창(`가시나무에_매달린_말들/index.html`)과는 따로 둔 랜딩페이지입니다. 작품 파일은 건드리지 않습니다.

- 뿌리와 줄기 클로즈업에서 시작해 나무를 오빗으로 훑으며 줌아웃하고(약 13초), 그동안 장면은 아스키로, 걸린 말은 실제 글자로 3D 위치에 그립니다.
- 정면에 정착하면 글자 칸이 줄 단위로 흩어지며 작품의 가는 선·금빛 전구 모습으로 바뀌고, 제목과 버튼이 떠오릅니다. 이후엔 마우스에 따라 나무가 살짝 돌아갑니다.
- 나무 생성·흔들림·말 사슬은 작품 코드를 그대로 가져와(`sim.js`) 작품과 같은 나무에 같은 말이 걸립니다.
- 아래 입력창에 쓴 말은 빈 가지에 한 글자씩 걸립니다 (이 화면에서만, 저장하지 않음).
- 오프닝 동안에는 메뉴 없이 화면 전체가 나무입니다. '건너뛰기'로 넘길 수 있고, '전체화면' 버튼이나 `F` 키로 브라우저 전체화면이 됩니다(브라우저는 클릭 없이 자동으로 켜는 걸 막음).
- 웹용으로 가볍게: 걸린 말 24개(작품은 50개), 줄기 띠 6가닥, 계보선 3분의 1, 해상도 상한 1.5배. 프레임이 22ms를 넘으면 해상도를 자동으로 한 단계씩 낮춥니다.
- 움직임 줄이기 설정이면 바로 정착 화면으로 시작합니다.

## 사이트 보기

저장소 루트에서 로컬 서버를 띄우고 `/site/`를 엽니다. 작품 실행 링크(`../가시나무에_매달린_말들/` 등)가 저장소 안의 작품으로 이어지므로 루트에서 띄워야 합니다.

```bash
python3 -m http.server 8790
```

브라우저에서 http://127.0.0.1:8790/landing/ (작품 랜딩) 또는 http://127.0.0.1:8790/site/ (작업 소개)를 엽니다. Claude 데스크톱 앱에서는 `.claude/launch.json`의 `site` 미리보기가 이 주소에 연결됩니다.

히어로의 새는 코드로 그려서 외부 이미지가 필요 없습니다.

- 감지 서버 가상환경 `vision/.venv`(약 800MB): `vision/setup_vision.command`로 다시 만듦
- TouchDesigner 자동 백업과 개발용 파일
